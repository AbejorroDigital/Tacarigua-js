Acerca del Proyecto

TacariguaJS es un framework modular de alto rendimiento diseñado desde cero para la ejecución de juegos 2D sin pausas de depuración por Recolección de Basura (Garbage Collection). Implementa un pipeline RHI sobre WebGPU, arquitectura basada en Entidades, Componentes y Sistemas (ECS) y soporte para ejecución asíncrona mediante Web Workers y Worklets.

Uso Rápido

Importación directa en módulos ECMAScript:

import { Engine, World } from 'https://tacariguajs.netlify.app/dist/tacarigua.min.js';

const app = new Engine({
  renderer: 'webgpu',
  canvas: document.getElementById('gameCanvas')
});

app.start();
